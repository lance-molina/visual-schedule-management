# docs/

| File / folder | What it is |
|---------------|------------|
| `api.md` | REST contract the frontend and backend code against |
| `erd.md` | Entity-relationship diagram (Mermaid, renders on GitHub) |
| `deployment-plan.md` | Hosting choice, environment variables, release steps |
| `technical-documentation/` | Technical document source, including `design-decisions.md` |
| `user-manual/` | User manual source |
| `research-paper/` | Research paper source (IEEE) |
| `usability/` | Consent form, task list, SUS sheet, raw data |
| `screenshots/` | Screenshots (fictional data only) |

Source files may be `.docx` or `.md`. Keep the final PDFs next to their sources.
